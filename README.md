# 🧮 Z-Calculator

Application calculatrice Android moderne et signée.

## 📱 Fonctionnalités
- Interface moderne et responsive
- Opérations basiques (+, -, ×, ÷)
- Design épuré
- Application signée pour publication

## 📦 Build
L'application génère automatiquement :
- APK signé (pour installation directe)
- AAB signé (pour Google Play Store)

## 🔐 Signature
Signée avec un certificat de release valide.

## 🚀 GitHub Actions
Build automatique à chaque push sur la branche main.
